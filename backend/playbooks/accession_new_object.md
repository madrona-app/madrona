# Accession a New Object

Use this when you're adding a new object to the permanent collection — typically after an acquisition has been approved by the collections committee. This is the step that turns a prospective item into an accessioned, cataloged record with its own object number.

## Where to go in Madrona

Accessioning is a two-stage flow:

1. **Collections → Transactions → Acquisitions** — track the committee-level decision, the source, and the formal acceptance.
2. **Collections → Collection → Cataloging** — after the acquisition is approved, create the catalog record for the object itself. If you started from an object entry, link both.

## Essential fields for procedure compliance

Start with the identifiers. Everything else depends on them.

1. **Object number** — your accession number, following the institution's scheme (`YYYY.NNN.1`, `MUS-00001`, etc.). Must be unique.
2. **Object name** — the short descriptor you'd use in a label or a spreadsheet ("painting", "shell gorget", "letter").
3. **Object type** — broader classification (painting, sculpture, photograph, textile, etc.). Drives downstream templates and reports.
4. **Brief description** — one or two sentences. Include enough to tell it apart from similar items.
5. **Materials** — what it's made of, using controlled vocabulary where possible. Ask Guide to look up the AAT term if you're unsure.
6. **Measurements** — dimensions, weight where relevant. Include units and what was measured (height, width, depth, diameter).
7. **Current location** — where the object physically lives *right now*. If it doesn't have a home yet, create a location record first.
8. **Acquisition method and date** — gift, purchase, bequest, transfer, etc., and when.
9. **Credit line** — the donor credit you'd show on a label. Required for many grant reports.

## Production and history

When known, record:

- Creators (artists, makers, workshops) via the constituent linker, not free text
- Creation date — use display, earliest, and latest forms; don't mix them
- Creation place — city or region, using a place authority where available
- Provenance — a chronological chain of owners. Be strict about this for anything that may have changed hands before 1946.

## Before you save

- Is the object number unique? Madrona will warn you if not.
- Do you have condition information? If yes, file a condition report; if not, flag it as "needs assessment".
- Is this object culturally sensitive? Classifications like *ethnographic*, *human remains*, or *funerary* trigger NAGPRA review — Madrona will surface the requirements automatically.

## After accessioning

- Open a condition report if you haven't already.
- Add a photo via the media section. Records without an image slow down every future workflow.
- Consider whether the object needs immediate conservation, special storage, or a publication decision.

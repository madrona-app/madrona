# Set Up an Exhibition

Use this when you're planning a new exhibition — from initial concept through object selection, installation, and opening. This playbook covers the collections management side (objects, loans, condition, insurance) rather than the curatorial or design side.

## Where to go in Madrona

**Collections → Exhibitions → Exhibitions** and press **New exhibition**. If you're adding objects to an existing exhibition, find it in the list and open its workspace.

## Planning phase

Start with the basics:

1. **Exhibition title** — the working title. Can be updated later.
2. **Dates** — planned opening, closing, and any travel dates if the show tours.
3. **Venue(s)** — where the exhibition will be held. If it's at your own institution, link the venue. If touring, add each venue with its dates.
4. **Curator / organizer** — who is responsible for the exhibition content.
5. **Description** — what the exhibition is about. This becomes the basis for catalog text, press releases, and web content.

## Object selection

Add objects to the exhibition via the **Objects** section:

- Search your collection and link objects directly
- For objects you need to borrow, create loan-in requests from the exhibition — Madrona tracks the relationship
- For each object, record the display method, position, and any special requirements (lighting, climate, security)

Before finalising the object list, check each object for:

- **Condition** — is it fit to display? Schedule condition reports for any object that hasn't been checked recently.
- **Rights** — can you display it? Are there restrictions on photography, reproduction for the catalog, or online promotion?
- **Availability** — is it already committed to another loan or exhibition during the same period?
- **Conservation needs** — does it need treatment, framing, mount-making, or cleaning before display?

## Loans for the exhibition

If borrowing objects from other institutions:

1. Create a loan-in record for each lending institution
2. Link the loan to the exhibition so Madrona tracks the purpose
3. Send facilities reports to lenders who request them
4. Arrange insurance or indemnity coverage for each borrowed object
5. Coordinate condition reporting — you'll need intake condition reports when objects arrive and comparison reports when they return

## Installation and opening

As the exhibition approaches:

- File condition reports for all objects before installation
- Record movements from storage to the exhibition gallery
- Verify insurance coverage is active for all objects (owned and borrowed)
- Document the installation with photographs

## De-installation and return

After closing:

- File de-installation condition reports
- Process loan returns for borrowed objects — each gets a return condition report and a dispatch
- Move owned objects back to storage — record each movement
- Close the exhibition record once all objects are accounted for

## Common pitfalls

- Not checking loan availability early enough. Lenders need months of lead time, and popular objects may be committed to other shows.
- Forgetting to order condition reports before installation. The pre-display baseline is essential for insurance and for detecting any damage during the run.
- Not recording object movements into and out of the gallery. If an object goes missing during de-installation, the movement history is the audit trail.
- Treating the exhibition as closed when the show ends. The exhibition isn't done until every borrowed object is returned and every condition report is filed.

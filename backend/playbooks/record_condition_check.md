# File a Condition Report

Use this to document the physical state of an object at a point in time — on accession, before a loan goes out, after a loan comes back, before conservation, or during routine collection monitoring. Condition reports are the legal and conservation trail for every object.

## Where to go in Madrona

**Collections → Care & Risk → Condition Reports** and press **New condition report**. You can also start one from an object's workspace via the **Condition** tab — Madrona will pre-link the object.

## What to record

1. **Object** — link to the specific object (don't rephrase the object number; use the record linker).
2. **Inspection date** — when you actually examined the object, not when you're filling out the form.
3. **Inspector** — the person who did the examination. Usually a conservator, curator, or trained registrar.
4. **Purpose** — why this check: accession baseline, pre-loan, post-loan, routine, pre-treatment, incident response.
5. **Overall rating** — a single summary: excellent, good, fair, poor, or critical. This drives downstream decisions.
6. **Condition description** — the narrative. What you see, in plain clinical language. No interpretation, no cause-of-damage speculation unless obvious.
7. **Component-level notes** — if the object has distinct parts (frame vs. canvas, base vs. figure, binding vs. text block), describe each separately.
8. **Photographs** — high-resolution images of overall state, any areas of concern, and reference marks. Condition reports without photos are barely useful.

## Using the vocabulary

Condition terminology is controlled — "foxing" and "mould" and "accretion" mean specific things. If you're not sure which term applies, ask Guide to look it up in the AAT. Using the wrong term can send a conservator on the wrong path.

## When condition is a concern

If the overall rating is **fair** or worse, or you noticed something new since the last check:

- Flag the object for conservator attention
- Open a conservation treatment record if treatment is planned
- If damage is new and the cause is unclear, file an incident report
- Update the object's conservation priority

## Pre-loan and post-loan reports

These two are a matched set. Before a loan goes out, file a detailed baseline report. When the objects come back, file a comparison report that explicitly references the pre-loan state — Madrona links them automatically.

Any change in the post-loan report becomes the legal basis for a claim against the borrower or their insurer. Be specific.

## Common pitfalls

- "In good condition" as the entire narrative. Future readers need to know *what you looked at*.
- Recording only overall state and not the components. A good report lists every area you inspected, even the ones that were fine.
- No photos. A report is only as useful as the visual reference accompanying it.
- Writing interpretations instead of observations. "Appears to have been dropped" is a guess. "New crack running from lower-left corner, 3 cm long" is a fact.

# Run an Inventory Audit

Use this when you need to verify the physical location and condition of objects in your collection — whether it's a full collection audit, a spot-check of a storage area, or a targeted count of objects going out on loan. Inventory is the fundamental accountability question: do we know where everything is?

## Where to go in Madrona

**Collections → Inventory → Scanner** for barcode-driven scanning. **Collections → Inventory → Barcode Labels** to print labels. **Collections → Governance → Audit Campaigns** to plan and track a formal audit campaign.

## Planning an audit

Before you start scanning:

1. **Define the scope** — what are you auditing? A single storage room, a department's holdings, objects on display, the entire collection? Create an audit campaign in Madrona to track scope and progress.
2. **Print barcode labels** — if objects don't already have barcodes, print and attach them first. Madrona generates labels from the object records.
3. **Prepare the scanner** — use Madrona's built-in barcode scanner (phone camera) or a handheld scanner that feeds into the scan history.
4. **Assign staff** — who is scanning which areas? The audit campaign tracks who scanned what and when.

## During the audit

For each object:

1. **Scan the barcode** — Madrona looks up the object by barcode and shows its record.
2. **Verify the location** — is the object where the system says it is? If yes, confirm. If no, update the location.
3. **Check condition** — a quick visual check. If anything looks wrong (damage, pest evidence, environmental concern), flag it for a full condition report.
4. **Note discrepancies** — object not found? Wrong object in this location? Unknown object without a barcode? Record everything.

## After the audit

1. **Review discrepancies** — objects marked "not found" need follow-up. Check if they were moved, loaned, or misplaced. Don't jump to "missing" — most discrepancies have mundane explanations.
2. **Update locations** — for every object that was in the wrong location, record a movement to the correct one.
3. **File condition reports** — for anything flagged during the scan.
4. **Generate the audit report** — the campaign summary shows coverage, discrepancies, and completion rate.
5. **Close the campaign** — once all discrepancies are resolved.

## Procedure context

There is no dedicated "Inventory" procedure; the Location and Movement Control procedure requires that you can account for every object at any time. Regular inventory audits are how you prove compliance. Most accreditation bodies expect at least a partial inventory annually and a full inventory on a rolling cycle (typically 5-10 years for the entire collection).

The Inventory requirements in Madrona (object number, object name, brief description, object status, current location) are the minimum fields you need to be able to identify and locate an object. If any of these are empty, the object can't pass an inventory check.

## Common pitfalls

- Auditing without barcodes. Manual number matching is slow and error-prone. Print labels first.
- Not recording "object found in correct location" — only recording discrepancies. The positive confirmations are evidence of coverage; without them you can't prove what you checked.
- Treating "not found" as "missing" immediately. Give staff 48 hours to check loan records, recent movements, and adjacent shelves before escalating.
- Doing a full audit without a campaign. Ad-hoc scanning doesn't track coverage — you won't know which areas were checked and which were missed.
- Not updating locations in real time. If you scan, find an object in the wrong place, and don't update the record until later, someone else may move it again in the interim.

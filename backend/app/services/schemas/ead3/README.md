# EAD3 schema (vendored)

`ead3.rng` is the official Encoded Archival Description 3 Relax NG schema,
**EAD3 release 1.1.1 (2019-12-16)**, developed by the Society of American
Archivists' Technical Subcommittee for Encoded Archival Description and hosted
by the Library of Congress.

- Downloaded from: https://www.loc.gov/ead/ead3.rng
- Identical to `ead3.rng` in the SAA repository https://github.com/SAA-SDT/EAD3
  (git blob `b622a2d90e8863451fa55d1b4ce5c54d4d6856e6`)
- Licence: CC0 1.0 Universal (the SAA-SDT/EAD3 repository licence), reproduced
  in `LICENSE` in this directory.

Used by the tests to validate Madrona's EAD3 export (app/services/ead_export.py).
Do not edit it; replace it with a newer official release and update this file.
